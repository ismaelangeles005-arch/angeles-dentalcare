# Desktop App

Electron shell seguro para Angeles DentalCare.

Comandos previstos desde la raiz:

```powershell
npm run desktop
npm run desktop:dev
npm run desktop:build
```

Antes de ejecutar, instala dependencias en la raiz del proyecto:

```powershell
npm install
```

La aplicacion desktop conserva el frontend/backend existentes para no romper modulos clinicos durante la transicion.
