# Iconos de Angeles DentalCare

`icon.ico` y `icon.png` son placeholders tecnicos para permitir la generacion del instalador Windows.

Antes de entregar a clientes, reemplazar ambos archivos por el icono oficial del producto:

- `resources/icons/icon.ico`
- `resources/icons/icon.png`

No usar rutas absolutas en `electron-builder.json`; la configuracion ya apunta a esta carpeta.
